패스 창과 + 버튼

재화 옆 "+" 버튼을 PixelLab 그림으로 바꾸고, 패스·순위·기록을 아래 창 대신 화면 가운데 창으로 띄웁니다. 패스 창은 "사면 무엇을 얻는지"를 맨 위에 크게 보여 줍니다.

1. 재화 + 버튼

PixelLab으로 그린 32px 버튼입니다. 게임에서는 22px로 골드·영혼석 숫자 오른쪽에 붙습니다. 누르면 그 재화 탭으로 상점이 열립니다.

23491A. 보라 돌 + 금 테두리 재화 표시 틀과 가장 잘 어울림
23491B. 초록 구슬 "더하기"가 가장 또렷, 색이 튐
23491C. 붉은 루비 마왕성 붉은 색, 눈에 잘 띔
23491D. 금화 골드 아이콘과 비슷해 헷갈릴 수 있음

2. 패스 창 (가운데)

패스를 사면: 패스 10단계에서 흑룡 외형 영구 소장(해골 군주는 없앰) · 외형은 가지고만 있어도 마왕 능력치 +10%(외형마다) · 패스 줄 보상(골드 30k·영혼석 200, 무료 줄의 약 4배). 산 뒤에는 위 미리보기가 줄어들고 보상 트랙이 커집니다.

3. 순위·기록 (가운데)

패스와 같은 가운데 창으로 띄웁니다. 순위 창은 "순위 | 공성" 두 탭만 있고 패스 탭은 빼서, 순위를 눌러도 패스가 섞이지 않습니다. 기록 창 내용은 지금 그대로입니다.

정해 주실 것

  • + 버튼: A 보라 돌(추천) / B 초록 구슬 / C 붉은 루비 / D 금화 / 다시 그리기
