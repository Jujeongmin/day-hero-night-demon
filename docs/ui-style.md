# UI 스타일 (승인: 2026-09-28)

## 구조: 방치형
- 메인 화면은 항상 마왕성 탑(`public/sprites/tower.png`, 224×400). 기획서 B안 모양.
- 탑 단 = 위에서부터 옥좌 · 3층 · 2층 · 1층(성문). 각 단의 위치(%)는 `src/screens/CastleScene.tsx`의 `THRONE`/`TIERS`.
- 잠긴 층은 어둡게 + `성 Lv.N` 표시. 누르면 강화 창이 열린다.
- 층을 누르면 그 층 편성 창이 열린다. 첫 방문 때만 1층에 "층을 눌러 몬스터 배치" 힌트.
- 아래 창(sheet)은 화면의 약 1/3(34%). 목록은 창 안에서 스크롤. 같은 탭을 다시 누르면 닫힌다.
- 창이 열리면 [출정] 버튼은 숨긴다(탑을 가리지 않게).
- 탭 4개: 강화 · 기록 · 리그 · 상점. 편성은 탑을 눌러서.
- 공략 중: 탭을 숨기고, 위는 전투, 아래 창은 궁극기 전용.
- 전술은 자동(`autoTactic`, `server/src/raid.ts`): 적이 2명 이상이면 집중, 아니면 돌격. 플레이어는 고르지 않는다. 끝나면 결과를 아래 창으로 띄우고 탑으로 돌아온다.

## 소리 (승인: 2026-09-28)
- 파일과 출처는 `public/audio/CREDITS.md` (Mixkit, 출처 표기 불필요). 서비스는 `src/services/audio.ts`.
- 홈 BGM Dark Shadows, 전투 BGM Sparta. 효과음: 탭·공격·피격·궁극기·층 돌파·전멸·털림·구매·마왕 포효.
- 승리음은 원본 8초를 코드에서 2.5초에 페이드아웃(`SFX_MAX_MS`). 재화 표시 가운데 `소리/무음` 버튼, 설정은 localStorage.
- 전투 소리는 `src/render/sfxMap.ts`가 프레임 효과에서 고른다. 첫 입력 전에는 브라우저가 소리를 막으므로 `unlockAudio`가 첫 pointerdown에서 푼다.

## 소환·방치·각성 (2026-10-02)
- 소환: 탑 왼쪽(전투력 아래) 제단 아이콘 → 전체 화면. 위는 제단 그림 + "영웅 이상까지 n회" + 확률 보기, 아래는 1회·10+1회 버튼. 결과는 카드가 0.15초마다 뒤집히고(누르면 모두), 등급 빛(희귀 파랑·영웅 보라·전설 금), 처음 얻은 외형 NEW, 중복은 바꿔 준 영혼석. 효과음은 기존 구매·궁극기·마왕 소리 재사용.
- 외형 입히기: 소환 화면이 아니라 강화 창 몬스터 줄의 "외형: ○○ +10% ▸" 칩(누를 때마다 기본 → 외형 → …). 전설 마왕 외형은 설정의 마왕 외형에서.
- 방치 보상: 오른쪽 패스 아래 보물상자 + 금액 + "방치 보상"(소환 아이콘과 같은 꼴), 0이면 흐리게.
- 각성: 강화 창 한 목록. 레벨 50이면 같은 자리 버튼이 "각성 (영혼석 N)". 마왕 각성은 성 줄 바로 아래. 별은 이름 옆과 유닛 머리 위에 동·은·금 별로.
