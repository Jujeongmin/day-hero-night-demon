# UI 스타일 (승인: 2026-09-28)

## 구조: 방치형
- 메인 화면은 항상 마왕성 탑(`public/sprites/tower.png`, 224×400). 기획서 B안 모양.
- 탑 단 = 위에서부터 옥좌 · 3층 · 2층 · 1층(성문). 각 단의 위치(%)는 `src/screens/CastleScene.tsx`의 `THRONE`/`TIERS`.
- 잠긴 층은 어둡게 + `성 Lv.N` 표시. 누르면 강화 창이 열린다.
- 층을 누르면 그 층 편성 창이 열린다. 첫 방문 때만 1층에 "층을 눌러 몬스터 배치" 힌트.
- 아래 창(sheet)은 화면의 약 1/3(34%). 목록은 창 안에서 스크롤. 같은 탭을 다시 누르면 닫힌다.
- 창이 열리면 [출정] 버튼은 숨긴다(탑을 가리지 않게).
- 탭 4개: 강화 · 기록 · 리그 · 상점. 편성은 탑을 눌러서.
- 공략 중: 탭을 숨기고, 위는 전투, 아래 창은 궁극기 전용.
- 전술은 자동(`autoTactic`, `server/src/raid.ts`): 적이 2명 이상이면 집중, 아니면 돌격. 플레이어는 고르지 않는다. 끝나면 결과를 아래 창으로 띄우고 탑으로 돌아온다.

## 원칙 (사용자 지시)
- 정보를 적게. 한 화면에 필요한 것만.
- 마우스(클릭/터치)만으로 전부 가능. 키보드 입력·드롭다운 없음.
- 한눈에 이해되게. 설명문 대신 짧은 라벨.
